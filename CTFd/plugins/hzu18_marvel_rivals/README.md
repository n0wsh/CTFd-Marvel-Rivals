# HZU18 Marvel Rivals Plugin

CTFd plugin for the HZU18 final-round hero selection layer.

The plugin provides:

- original placeholder hero catalog data
- captain-only team hero picking with a final confirmation lock
- dedicated `/hero` page for team hero selection
- manual admin lock and enforced unique-hero picks across teams
- public `/api/v1/hzu18/*` endpoints for the standalone scoreboard
- public replayable event feed for confirmed hero picks and organizer announcements
- solve-side live events for correct flags, first blood, and leader changes

No Marvel, Marvel Rivals, or third-party art/audio assets are included.
